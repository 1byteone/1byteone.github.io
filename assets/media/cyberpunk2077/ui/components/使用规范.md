# Cyberpunk UI 裁片使用规范

本组件库由用户提供的 HUD 图集按区域裁切而来。运行时使用的是可独立引用的 PNG 裁片；页面内容、文字、按钮行为与可访问性仍由 HTML、CSS 和 JavaScript 提供。

## 前端术语

| 术语 | 本库中的含义 | 推荐用途 |
| --- | --- | --- |
| **UI chrome / interface skin（界面外壳/皮肤层）** | 叠加在真实 HTML 控件或容器之上的视觉表皮，裁片只表达边框、角标、扫描纹理等装饰 | 弹框边角、按钮纹理、面板轮廓 |
| **decorative asset layer（装饰资产层）** | 由 CSS 伪元素承载的独立贴图层，与内容和交互分层 | 避免把文字烘焙进图片，也避免贴图挡住点击 |
| **state marker（状态标记）** | 表达当前状态的小型图形组件 | 选中、警告、已发布、方向等 |
| **progress rail / telemetry rail（进度轨/遥测轨）** | 横向或纵向的细长视觉构件 | 列表 hover、加载/进度、仪表刻度 |
| **sprite atlas（精灵图集）** | 多个图形合并在一张大图，通过精灵坐标显示局部 | 仅作为源文件；网页运行时优先引用本库裁好的独立 PNG |
| **nine-slice / 9-slice（九切片）** | 将一个完整可缩放边框按四角、四边和中心切片拉伸的容器技术 | 仅当素材专门按九切片边框制作并验证后使用 |

当前运行时裁片是独立 PNG，而非统一尺寸的九切片框。**不要把普通裁片写成 `border-image`，也不要拉伸小图来包任意尺寸的大弹窗。** 对响应式面板使用真实 CSS 边框/裁切形状，裁片只作为局部角框、刻度、状态符号或细轨道；如果将来提供可九切片的源框，再为它单独定义 slice 参数。

## 已落地的 CSS 组件 API

通用外壳由 `.cp77-asset-skin` 提供：它建立独立层叠上下文，在 `::before` 上绘制背景资产，并确保直接子级内容位于图层上方。通过修饰类选择资产语义：

- `.cp77-skin--button`：按钮纹理。
- `.cp77-skin--frame-corner`：弹框右上角框饰。
- `.cp77-skin--signal-frame`：数据面板的低对比框线。

示例：

```html
<a class="cp77-button cp77-button-primary cp77-asset-skin cp77-skin--button" href="/zh/blog/">
  <span>浏览文章</span>
</a>

<section class="cp77-command-dialog cp77-asset-skin cp77-skin--frame-corner"
         role="dialog" aria-modal="true" aria-labelledby="command-title">
  <h2 id="command-title">检索工程档案</h2>
  <!-- 输入、结果与键盘操作依旧是原生 HTML -->
</section>
```

添加新皮肤时，只新增 `--cp77-skin-image`、`--cp77-skin-size`、`--cp77-skin-position`、`--cp77-skin-inset` 和 `--cp77-skin-opacity` 映射，不要复制整段伪元素实现。装饰层必须设 `pointer-events: none`，且不能包含唯一信息；有意义的状态文字仍需放在 DOM 中。

## 组合规则

1. 先建立组件的内容结构与语义，再把裁片作为外壳、信号或状态层加入。
2. 每个控件最多选择一个主要皮肤；图标、轨道和角框只在需要传达状态或边界时增加。
3. 保留原生文本、真实按钮/链接、键盘焦点和状态属性。hover、focus、active、disabled、loading 由 CSS/DOM 状态驱动，贴图本身不携带状态逻辑。
4. 用 `background-size: contain` 或固定比例尺寸保护裁片比例。只有纹理可安全重复时才使用 `repeat`；有固定角线的素材不得拉伸。
5. 移动端缩减装饰密度，不缩小正文可读性，也不让素材决定容器高度。
6. 优先使用 manifest 中 `runtime-used` 的单一裁片。`reference-only` 是复合面板或含多个控件的参考图，不可直接铺在按钮、卡片或弹框下方；`candidate` 须先检查预览并更新 manifest。

## 资产角色速查

- `icons/`：方向、状态和索引符号，作为小尺寸 marker 使用，不作为大面积面板背景。
- `vertical/rail-*`：细轨和列表状态线，以 `object-fit: contain` 或背景 `contain` 显示。
- `vertical/arrow-grid-*`：行内导航方向标记，尺寸跟随图标槽位，不承担链接文案。
- `wide/large-data-frame-*`：局部数据框/角饰候选；不能不经九切片验证就拉伸成完整容器。
- `wide/loading-stripe`：窄进度或遥测装饰，不能单独暗示实际加载进度；真实进度另用语义值。
- `wide/chart-area`、`wide/radial-readout-*`：当前 manifest 标记为参考资产时只作素材参考，不能误接为实时数据图表。
