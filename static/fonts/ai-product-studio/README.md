# AI Product Studio 字体资产

本目录只包含可再分发的开源字体文件，用于保证 AI Product Studio 在不同系统中的字形、字重和基线稳定。

- `Inter-Variable.ttf`：Inter variable font，来源 [Google Fonts](https://github.com/google/fonts/tree/main/ofl/inter)，许可证见 `Inter-OFL.txt`。
- `IBMPlexMono-*.woff2`：IBM Plex Mono 字重文件，来源 [IBM Plex](https://github.com/IBM/plex/tree/master/packages/plex-mono)，许可证见 `IBM-Plex-License.txt`。

Linear 的私有字体和图标字库没有复制；页面使用本地 `APS Inter` / `APS Plex Mono` 字体契约与原创 CSS 图标几何，保证 YOYO 内容在中英文路由中的可读性和渲染稳定性。
