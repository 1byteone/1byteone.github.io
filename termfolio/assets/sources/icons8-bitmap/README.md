# Icons8 Bitmap reference assets

These files are the locally archived preview files used to prepare the clean
Bitmap-style illustrations in `public/images/blog/bitmap/`. They are kept
outside `public/` so a watermarked preview cannot be served by the application.

- Source style: [Icons8 Bitmap illustrations](https://icons8.com/illustrations/style--bitmap)
- Primary illustration: [Planet earth in Space Bitmap style](https://icons8.com/illustrations/illustration/bitmap-planet-earth)
- Related illustration collection: the “Related illustrations in the Bitmap style” section on the primary page
- Creator shown by the source page: [Icons8 / Ouch!](https://icons8.com/illustrations)
- License reference: [Icons8 license](https://icons8.com/license)

The public PNGs are local, cleaned, two-tone Bitmap derivatives prepared for
the blog's article covers and related-illustration shelf. The batch catalog
contains 100 references and its generated index is at `lib/bitmap-catalog.json`.
Keep this attribution with the project when the site is redistributed, and
verify the applicable Icons8 terms before using the assets outside the
authorized learning use.
